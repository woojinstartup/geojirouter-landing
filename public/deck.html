03

기존 코드에 연결

OpenAI 호환 클라이언트에
로컬 주소와 키를 설정합니다.

OPENAI-COMPATIBLE / LOCAL

한 주소로,
여러 무료 경로에.

const client = new OpenAI({
  baseURL: "http://127.0.0.1:18473/v1",
  apiKey: process.env.GATEWAY_TOKEN
});

로그인·약관 동의는 사용자가 진행하며, 호출 키는 로컬 게이트웨이에 설정한 키입니다.

엔드포인트는 백엔드 저장소 README의 127.0.0.1:18473/v1 기준. 랜딩의 localhost:4141 예시와 구분. GATEWAY_TOKEN는 예시 환경변수 이름이며 게이트웨이에 구성한 로컬 bearer 키를 넣어야 함. Aside CLI는 가입 보조 흐름이며 완전 자동 가입을 주장하지 않음.
